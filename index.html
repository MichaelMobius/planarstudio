DIAGNÓSTICOsolver v5 · desmontaje inverso + contacto de unión

El solver v5 parte de la pose final real y desmonta pieza por pieza. Durante el tramo en que una pieza atraviesa su propia ranura, el compañero de esa unión se trata como contacto previsto de encaje; todas las demás piezas siguen siendo obstáculos. Al terminar de liberar la ranura se vuelve a verificar contra todo el conjunto. Las rutas posteriores usan colisión 3D y muestreo adaptativo; no constituye una prueba matemática continua.

Cómo diseñar

  1. Plano por gesto. Arrastra en una zona vacía para crear un plano libre. Si haces clic o arrastras sobre una pieza existente, se crea un plano exactamente perpendicular a ella usando su orientación local actual. Shift ajusta a 15°, Ctrl a los ejes U/V y Alt fuerza el gesto libre aunque empieces sobre una pieza.
  2. Editar dibujo 2D. El plano se convierte en una mesa de dibujo ortográfica. Usa la rueda para zoom y Espacio + arrastre para desplazarte.
  3. Calcar una imagen. Importa referencias, baja su opacidad y dibuja la silueta con pocos nodos Bézier.
  4. Volver al espacio. Al terminar, la curva cerrada se convierte en una pieza con grosor real. El gumball permite mover, escalar y rotar sobre ejes locales.
  5. Repetir. Crea otras piezas en otros planos; el sistema calcula intersecciones geométricas reales.
  6. Patrones. Haz clic derecho sobre una pieza para crear simetrías, matrices rectangulares o polares y distribuir costillas a lo largo de otra pieza. Las copias permanecen vinculadas a la pieza maestra. Puedes desvincular una instancia o usar Fijar para convertir todo el patrón en piezas independientes.
  7. Fabricar. Define kerf y holgura, genera ranuras y abre Corte 2D. Allí ves exactamente las piezas aplanadas. Nesting prueba rotaciones 0°/90°, evita colisiones poligonales, respeta margen/separación y crea varias planchas si hacen falta.
  8. Ensamblar. Abre Ensamblaje para ver el grafo y la secuencia inferida desde la pose final real. El solver desmonta virtualmente las piezas, verifica colisiones y luego invierte el orden para simular el montaje.
  9. Calibrar. En Fabricación abre Calibrar láser / material, genera un peine SVG, córtalo y elige la ranura K0.xx que encaje mejor. Ese valor se aplica como kerf efectivo y puede guardarse como perfil.
